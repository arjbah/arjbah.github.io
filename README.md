#### Quick start
- Run local server: `hugo server`
- Edit site config: `hugo.yaml`
- Edit styles: `assets/css/extended/custom.css` 
- Edit markdown: `themes/PaperMod/layouts/partials/templates`
- Publish website: `hugo` followed by `git subtree push --prefix public origin gh-pages`
